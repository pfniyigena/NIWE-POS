# Return pick-ups (v1.62.0)

## How it works
1. The customer asks to return goods (My orders > Track, or My returns), as before.
2. Staff open **Online Store > Returns** and **Approve**. For a delivery order a **return code** is made and sent by e-mail and text. Choose the **driver** in the list next to Approve, or later in the "A driver collects the goods" box.
3. The driver opens his private link, sees **Returns to collect**, goes to the customer, and when the customer hands over the goods and gives the code, taps **Collect the goods** and types it.
4. The return becomes **Collected**. Staff check the goods when they arrive and press **Goods received: put back and refund**.

## Good to know
- No charge for the collection. The delivery fee is not refunded.
- A return of an order picked up at the shop has no code and no driver: the customer brings the goods back.
- Customer lost the code? **New return code (send again)** makes a new one and sends it; the old one stops working.
- Five wrong codes lock the return for half an hour; a new code unlocks it at once.
- Change the driver any time before the goods are collected. A refused return disappears from the driver's page.
- The driver never sees the code and sees only his own returns.
