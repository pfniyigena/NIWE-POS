# Release 1.52.0 - Online Store: drivers, delivery slips and run sheets

- **Drivers**: Online Store > Shop settings has a new "Drivers" card: a simple list (name, phone, note, active). A driver is not an employee record. A driver with orders still to deliver cannot be removed (switch him off instead).
- **Assign a driver on the order**: every delivery order (New, Accepted, Packed, Out for delivery) has a "Driver" choice that can be set or changed any time before delivery; the change is written in the order history. "Out for delivery" asks for a driver when none is set (as long as the shop has active drivers).
- **Delivery slip (PDF)**: one page per order with the customer, phone, address, area, note, driver, the goods to hand over, the total, the amount to collect (or "Already paid online: nothing to collect") and two signature lines (driver, customer). Not available for pick-up orders.
- **Run sheet (PDF)**: pick a driver (or "Not assigned") in the filter above the orders and press "Run sheet": all his orders still to deliver, grouped by area, with the number of stops and the cash to collect, and a tick column.
- **WhatsApp to the driver**: a link on the order opens WhatsApp to the driver with the order code, customer, phone, address and the amount to collect.
- **The customer is told**: once the order is out for delivery, the customer's order page shows "Your driver: name, phone" (the phone can be called), and the "on its way" text message / e-mail adds the driver's name and phone.
- Database: migration V87 (`online_driver`; driver columns on `online_order`). API: `GET/POST /api/online-store/drivers`, `PUT/DELETE .../drivers/{id}`, `POST .../orders/{id}/driver`, `GET .../orders/{id}/delivery-slip`, `GET .../delivery-run?driverId=`, orders list `?driverId=` (0 = no driver). Permissions: the same as the orders (view / manage). French texts.

Tested in the cloud (PostgreSQL, real server, headless browser): add and refuse an empty driver; assign, reassign and remove a driver; assigning to a pick-up order refused; "Out for delivery" without a driver refused with a clear message, then accepted after choosing; filter by driver and "Not assigned"; both PDFs produced and checked visually; the customer's order page shows the driver only when out for delivery; a driver with open orders cannot be removed. Not tested: sending the real "on its way" text to a phone, French screens, printing on paper.
