# Release 1.55.0 - Online Store: the customer portal

- **A real "My account" area in the shop**, at `/shop/account`. The 👤 button in the shop header now opens it (signed out, it shows the sign-in). Signed in, the customer has a menu on the left (a row of tabs on phones) and one page per entry, each with its own address so links and the back button work: **My orders** (`/shop/account/orders`), **My invoices** (`/invoices`), **My wish list** (`/wishlist`), **My returns** (`/returns`), **My addresses** (`/addresses`), **Loyalty points** (`/points`, only when the shop has loyalty points) and **My profile** (`/profile`, with sign-out and delete my account). The menu shows small counters (orders in progress, invoices, hearts, returns waiting for an answer).
- **My orders**: all orders of the account, with filters All / In progress / Delivered / Cancelled; **Track**, **Order again** (fills the cart with today's products and prices and opens the order form) and **Invoice** (PDF) on every completed order.
- **My invoices**: one line per invoice (number, order, date, total) with **Download (PDF)**.
- **My wish list**: the hearted products with price and stock, **Add to cart** (a product with options opens its page to choose them) and a heart to remove.
- **My returns**: every return the customer asked for, in any order, with its status (waiting for an answer, approved, refused, refunded), the goods, the reason, the shop's note and the refunded amount. Asking for a return stays on the order page.
- The cart is kept while the customer moves between the shop and the portal; the cart button stays in the header of the portal.
- The sign-in card opened from the order form is unchanged. `robots.txt` now also keeps search engines out of `/shop/account`.
- API: new `GET /api/public/store/account/returns`; `GET /api/public/store/account/orders` now also gives each order's invoice number. No database change. French texts.

Tested in the cloud (PostgreSQL, real server, headless browser, a mail server for the sign-in code): sign-in card when signed out; the seven menu entries and counters (Loyalty points hidden when loyalty is off); orders with the three filters; invoice PDF opened from My orders and My invoices; wish list cards, add to cart and cart counter, removing a heart; the returns list after a return was asked from the account; addresses and profile pages; cart kept going to the portal and back; Order again landing on the order form; unknown section falling back to My orders; phone width (tabs, no sideways scrolling). Not tested: French screens, loyalty page with real points.
